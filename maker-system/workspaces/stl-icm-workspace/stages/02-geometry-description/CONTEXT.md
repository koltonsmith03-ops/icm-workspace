# Stage 02 — Geometry Description

## Inputs
- `../01-intent-spec/output/intent.md`
- `../01-intent-spec/output/spec.md`
- Any clarifications the user gave after stage 01

## Process
1. Translate the specification into a precise geometric description.
2. Describe overall form, major features, wall thicknesses (only if given), mounting points, clearances, etc.
3. Use unambiguous language a human or later code stage can follow.
4. Still do **not** write OpenSCAD code in this stage.
5. Flag any remaining ambiguities.

## Outputs
Write to `output/`:

- `geometry.md` — Detailed geometric description. Organized by major components or features. No code.

## Checkpoint
Stop and show the geometry description. Wait for approval or corrections before stage 03.
